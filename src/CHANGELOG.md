# 更新记录

## v3.3.0 · 2026-08-31

- 删除迷你 OSD 中四枚独立玻璃圆球，CPU / GPU / 内存 / 温度改为无容器的液态数字
- 百分比字形本身承担水位表达：彩色液体从数字底部填充，液面只保留一条克制的非对称弧线和焦散亮边
- OSD 宽度从 548 缩至 428 像素，信息、间距和恢复入口重新排版，减少装饰件对数值的干扰
- 温度液位改按 30–100°C 映射，正常保持冷色，75°C 转暖橙、88°C 转红
- 液态数字无计时器、无常驻波浪，只在现有采样节奏下局部重画

## v3.2.1 · 2026-08-31

- 移除 OSD 右侧突兀的独立恢复球，将无边框展开入口收进主胶囊末端
- OSD 原生窗口裁剪由两个圆角区域合并简化为单一胶囊区域，消除按钮间隙与矩形底色露出
- 新增双击 OSD 空白处返回完整面板，保留直观入口的同时减少视觉噪声

## v3.2.0 · 2026-08-28

- 依据 Apple 2026 年 iOS 27 UI Kit 重新校准材料层级：内容层保持清晰平面，Liquid Glass 只用于外壳、控制组、设置浮层和 OSD 等功能层
- OSD 从奶白磨砂大胶囊改为暗色高透悬浮岛，使用局部白色镜面亮边、微弱冷色色散和背景透入建立厚度
- 四根模板化竖向水柱改为四枚液态圆形占用镜片，CPU 保持主层级，GPU、内存与温度采用一致的同心圆形语言
- 液态仪表移除默认气泡和塑料式椭圆头，改用更平缓的液面、细焦散线与双层明亮轮廓
- 主界面指标移除 M / D / G / ° 字母徽章，改为克制色点；顶部按钮和品牌区统一为同心圆角功能玻璃
- Clear 玻璃上的白色 OSD 信息增加透明暗色明度保护层；主界面文字较多的控件使用 Regular 玻璃，兼顾真实透色和可读性
- 边缘光学为 0 时彻底停止指针光源跟随；启用后也只对明显位移作 66 ms 合并更新，避免细碎鼠标事件反复重建材质
- 保持持久化绘图层、4 秒水位合并刷新和无常驻动画设计，不以持续波浪换取“新系统”观感

## v3.1.0 · 2026-08-28

- 新增可复用的原生矢量 `LiquidGauge`：根据确定占用率绘制液面弧、透明液体、镜面高光与少量气泡
- CPU 主仪表由传统圆环升级为垂直水位玻璃球，液面高度直接对应 CPU 占用率
- 内存、磁盘、GPU 与温度进度条升级为液态胶囊，保留原本简洁标题，不额外堆叠“水位”文案
- 迷你 OSD 的四条细横线改为四根短竖向玻璃水柱，在极小空间里仍能一眼比较 CPU / GPU / 内存 / 温度
- 液态控件拆成持久化绘图层：玻璃容器、完整液体、气泡和高光保持缓存，数值变化只移动裁剪区并重画一条很小的液面
- 主界面与 OSD 数字仍每 2 秒更新，水位合并为最多每 4 秒更新一次，任一指标跳变达到 6% 会立即刷新
- 不使用波浪计时器或常驻动画；常用渐变和高光画刷会冻结并复用

## v3.0.1 · 2026-08-28

- 撤下 HostBackdrop + VisualSurface 的窄边缘背景重采样：该路径在强度拉满时会把无效采样混成黑边，低强度时又缺少可感知价值
- “边缘折射”改为“边缘光学”，现在明确控制明亮内缘、轻微蓝紫色散、镜面高光与边缘厚度
- 所有边缘颜色均限制为白色或冷色透明高光，不再使用深色端点；`0` 完全关闭光学层，`100` 仍不会产生暗边或黑边
- 设置浮层会按强度显示“已关闭 / 轻微 / 清晰 / 强烈”的实际效果说明，原有 `Refraction` 设置值继续兼容
- 删除不再需要的独立 Windows Composition 视觉树，减少窗口合成路径和运行时复杂度

## v3.0.0 · 2026-08-28

- 按功能层级重构主界面：玻璃只用于窗体外壳、顶部控制组、设置浮层和迷你 OSD，监控内容改为一体化稳定阅读面
- 删除指标卡片、图表、进程榜之间重复的圆角外框，以细分隔线和留白建立层级，避免“每块内容都是卡片”的模板感
- 将透明度与折射滑条移入顶部“光学材质”浮层；内容区不再跟随透明度一起消失，两项设置继续自动保存
- 新增 Windows Composition HostBackdrop + VisualSurface GPU 边缘折射，滑条现在控制真实背景像素的窄边缘位移，最大 4.5 px
- 增加跟随指针的共享光源；只在指针移动或滑条变化时以 33 ms 合并更新，不运行常驻动画
- 设置浮层采用更高对比度的 Regular 玻璃，繁忙背景下仍能清楚阅读
- GPU 监控改为单个 PDH 通配查询，进程榜改为 NtQuerySystemInformation 原生快照；首次立即显示，之后每 30 秒刷新，结束进程与退出 OSD 时会立即请求更新
- 迷你 OSD 保持无外围矩形框的胶囊布局，统一为蓝色系性能强调与橙色温度强调

## v2.2.0 · 2026-08-28

- 重新建立玻璃层级：窗体底板继续真实透底，指标卡片、设备块和控制组件恢复为清晰可读的半透明实体
- 底部新增“透明度”滑条，可实时调整主界面与迷你 OSD 的组件透光量
- 新增“折射”滑条，用轻量矢量方式调整卡片边缘偏折与镜面高光强度，不启用高开销像素扭曲
- 两项设置会防抖写入程序目录下的 `Pulse.settings.json`，再次启动自动恢复
- 滑动期间最多每 40ms 合并应用一次视觉设置，并冻结生成的画刷，避免连续拖动造成卡顿

## v2.1.2 · 2026-08-28

- 修正 Windows 10 上窗口仍呈浅灰色的问题：底层从自带灰色明度混合的 Acrylic 改为原生 DWM Clear Blur Behind
- 完全移除原生材质的颜色染色，桌面和后方程序的真实颜色现在直接参与玻璃合成
- 删除原先在合成接口异常时启用的 93% 不透明浅灰兜底；任何情况下都不再把窗口退化为灰色面板
- 玻璃高光、卡片层次与 OSD 无整圈外框设计保持不变，仍由 GPU 合成且不截取桌面

## v2.1.1 · 2026-08-28

- 将主窗口与迷你 OSD 改为真正的高透玻璃，显著降低 Acrylic 染色和卡片遮罩浓度，后方窗口颜色可自然透入
- 移除 OSD 信息胶囊与恢复控制球的整圈外框，只保留短促的局部镜面高光
- 保留 DWM 原生 GPU 背景扩散与静态光学层，不引入桌面截图或持续运行的模糊着色器
- OSD 仍使用两个原生圆角区域的并集；两者之间没有透明大窗口，也不会拦截下方程序操作

- 迷你 OSD 改用原生 Acrylic，而不是透明窗口上的不透明黑色面板

- 主窗口同步强化光学边缘和卡片玻璃层次，继续保持 DWM GPU 合成的流畅度
